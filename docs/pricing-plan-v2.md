# ThreatGuard 価格プラン v2（最終決定 2026/03/06）

## 全体構造

- 初期費用なし
- 4プラン構成 + テイクダウン従量課金
- **年一括前払い（2ヶ月無料）がデフォルト**

## 無料診断（リードジェン）

- 1ドメイン × 1回 × 14日間閲覧（C案）
- 診断内容: ドメインスキャン、脅威一覧、AIリスク判定スコア、推定被害額
- 類似ドメイン一覧は上位5件のみ（残りはぼかし）
- テイクダウンには契約が必要
- 期限切れ後: 件数・スコアは表示継続、詳細はロック
- 週1メール通知「脅威が○件増えています」
- GitHub issue: #26

## 各プランの営業ポジション

- **Starter:** 「人を1人雇うより安い。最低限のフィッシング対策を自分で回せる」
- **Professional:** 「金融庁に聞かれた時に、ボタン一つで報告書が出せる」
- **Enterprise:** 「Web・メール・アプリ・ダークウェブ。フィッシング対策を丸投げ」
- **Enterprise+:** アンカー効果。個別見積。
