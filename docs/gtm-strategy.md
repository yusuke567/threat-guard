# ThreatGuard GTM（Go-To-Market）戦略

_最終更新: 2026-03-06_
_決定場所: Slack #pj-marketing「マーケティング＆セールス方法」スレッド_

---

## 基本方針

- **自社でセールスチームは持たない**（1人起業家 × AIエージェント体制）
- セルフサーブ＆クレジットカード決済で利用開始可能な基盤を構築
- PMF前は大塚CEOのネットワークによるファウンダーセールスで初期顧客を獲得
- PMF後はセルフサーブ + 代理店チャネルのハイブリッドモデルへ移行

---

## Phase 1: PMF前（現在〜初期顧客数社獲得）

### ゴール
- 初期顧客2-3社の獲得（コインチェック、オリパンワン等）
- プロダクトの価値検証とフィードバックループの確立
- セルフサーブ基盤の構築

### セールス
- **ファウンダーセールス**が主軸。大塚CEOの暗号資産業界ネットワークで直接アプローチ
- セールスチーム・代理店は不要（この段階では投資対効果が合わない）
- 初期顧客はハイタッチで獲得し、PMFの証拠を積む

### マーケティング
- プロダクト説明資料の作成
- 無料診断（1ドメイン × 1回 × 14日間）をリードジェンとして活用
- コンテンツは最小限（LP + 無料診断導線）

### 決済・オンボーディング
- Stripe決済基盤を構築（セルフサーブの入口として）
- サインアップ → 即利用可能な状態を目指す
- 目的: セールスチャネルとしてではなく、**オンボーディングコスト削減**
  - デモ → 「試してみてください」で自分で利用開始できる状態

### 請求方式（PMF前）
- クレジットカード決済（Stripe）
- 月契約・月払い（短期導入テスト用として提供）

## Phase 2: PMF後（ARR数千万〜）

_PMFの確証が得られた段階で詳細を策定する。以下は現時点の方向性。_

### セルフサーブの現実的な射程

| 価格帯 | セルフサーブ可否 | 根拠 |
|---|---|---|
| 〜月30万 | ✅ 可能 | 部門長決裁、クレカOKの企業が多い |
| 月50万（Starter） | ⚠️ グレーゾーン | 情シス部長〜CISO決裁。稟議必要だが通せるケースあり |
| 月100万〜（Professional） | ❌ ほぼ不可 | 役員決裁・稟議書・相見積もり・セキュリティチェックシートが必須 |
| 月200万〜（Enterprise） | ❌ 完全に不可 | 年額2400万。予算取り→複数回面談→PoC→稟議のフルプロセス |

**日本特有の壁:**
- 稟議文化: 月100万超は「なぜこのベンダーか」「既存製品との比較」が必須
- セキュリティ製品は「導入して問題が起きたら担当者の責任」→ 人からの説明・提案を求める傾向
- 大企業は請求書払い（NET30/60）が前提。クレカ決済不可の会社も多い

### 想定GTMモデル（ハイブリッド）

```
Tier 1: セルフサーブ（〜月50万 / Starter）
├── Stripe決済 + 請求書払い選択可
├── Web → 無料診断 → 有料転換
└── コンテンツマーケ（SEO / 事例記事）で流入

Tier 2: セールスアシスト（月50〜200万 / Professional〜Enterprise）
├── セルフサーブで入口は開けるが、商談が発生
├── 代理店 or パートタイムセールスが稟議支援
└── 稟議テンプレ・ROI資料・競合比較表を用意

Tier 3: 代理店チャネル（月200万〜 / Enterprise+）
├── セキュリティ専門ディストリビューター経由
└── PMF確認後・事例2-3社ができた段階で交渉開始
```

### 代理店戦略（PMF後）
- PMF前に代理店契約を結ぶのは時期尚早（実績がないと代理店も動かない）
- 事例が2-3社できた段階でセキュリティ系ディストリビューターにアプローチ
- 候補: マクニカネットワークス、SBテクノロジー、ラック等

### 競合のGTMモデル（参考）

| 企業 | カテゴリ | 日本展開モデル |
|---|---|---|
| Okta | IDaaS | 100%チャネルパートナー経由（日立ソリューションズ等）。セルフサーブなし |
| CrowdStrike | EDR | 日本法人 + ディストリビューター（マクニカ等）。セルフサーブなし |
| 1Password | パスワード管理 | SMBはセルフサーブ、エンタープライズはSales Contact。ハイブリッド |
| Bolster / PhishLabs / Red Points | ブランドプロテクション | 全社「Contact Sales」モデル。セルフサーブ提供なし |

### ThreatGuardの差別化ポイント
- **競合が全て「Contact Sales」モデルの中で、セルフサーブで即利用可能**
- 業界標準: デモ依頼 → 2週間後に営業 → PoC → 3ヶ月後に導入
- ThreatGuard: サインアップ → 即日検知開始 → 効果を見て稟議（ボトムアップ型）
- 特にSMB〜ミッドマーケット（従業員100-500名のEC/フィンテック）で差別化が効く
