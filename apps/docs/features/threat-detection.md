# 脅威検知

ThreatGuardは複数の監視チャネルで脅威を検知します。

## 類似ドメイン監視

御社ドメインに似た不審なドメインを自動検知します。

### 検知手法

| 手法 | 説明 | 例（example.comの場合） |
|------|------|------------------------|
| ホモグリフ攻撃 | 見た目が似た文字への置換 | examp1e.com, exаmple.com |
| タイポスクワッティング | 入力ミスを狙った登録 | examlpe.com, exampe.com |
| TLD変更 | ドメイン末尾の変更 | example.net, example.co |
| 接頭辞/接尾辞 | 前後に文字を追加 | myexample.com, example-login.com |

### 検知タイミング

- **定期スキャン**: 6時間ごとに自動実行
- **手動スキャン**: ダッシュボードから即時実行可能

## CT監視

Certificate Transparency（CT）ログを監視し、御社ドメインに関連する SSL/TLS 証明書の発行を検知します。

### 仕組み

```
証明書発行 → CTログに記録 → ThreatGuardが監視 → 不審な証明書を検知
```

### 検知対象

- 御社ドメインを含む証明書
- 類似ドメインの証明書
- ワイルドカード証明書

::: tip CISO向け補足
CTログはRFC 6962で定義された公開ログです。主要なCAは証明書発行時にCTログへの登録が義務付けられています。ThreatGuardはcrt.sh等のCTログアグリゲータを活用しています。
:::

## Webプローブ

検知したドメインの詳細情報を自動収集します。

### 収集情報

| 項目 | 説明 |
|------|------|
| スクリーンショット | ページの視覚的な状態 |
| HTTPヘッダー | サーバー情報、セキュリティヘッダー |
| SSL証明書情報 | 発行者、有効期限、SANs |
| WHOIS情報 | 登録者、登録日、Abuse連絡先 |
| IPアドレス | ホスティング情報 |
| HTMLスニペット | ページ内容のサンプル |

### 技術仕様

- ブラウザエンジン: Playwright（Chromium）
- スクリーンショット解像度: 1280x800
- タイムアウト: 30秒

## SNS監視

::: info Professional以上
この機能はProfessionalプラン以上でご利用いただけます。
:::

Twitter/X、Facebook、Instagramでの不正投稿を検知します。

### 検知対象

- 御社ブランドを騙るアカウント
- フィッシングURLを含む投稿
- 不正なキャンペーン・懸賞情報

### 対応SNS

| SNS | 対応状況 |
|-----|---------|
| Twitter/X | 対応済み |
| Facebook | 対応済み |
| Instagram | 対応済み |
| Telegram | 対応済み |
| Discord | 対応済み |

## ダークウェブ監視

::: info Enterprise以上
この機能はEnterpriseプラン以上でご利用いただけます。
:::

ダークウェブ上での御社関連情報の流出を監視します。

### 監視対象

- 顧客情報の漏洩
- アカウント情報の販売
- 内部情報の流出

## 偽アプリ検知

::: info Enterprise以上
この機能はEnterpriseプラン以上でご利用いただけます。
:::

iOS/Androidストアでの偽アプリを検知します。

### 監視対象

- 公式アプリを模倣したアプリ
- 御社ブランドを使用したアプリ
- マルウェア配布アプリ

## 検知フロー

```
監視チャネル → 脅威候補を検出 → AIリスク判定 → アラート通知
                                      ↓
                              ダッシュボードに表示
```
