# AIリスク判定

ThreatGuardは、Claude AIを活用して検知した脅威を自動分析します。

## 脅威分類

検知した脅威を5つのカテゴリに分類します：

| カテゴリ | 説明 | 推奨対応 |
|---------|------|---------|
| 🔴 **phishing** | フィッシングサイト確定 | 即時テイクダウン |
| 🟠 **brand_abuse** | ブランド悪用の疑い | 要調査・テイクダウン検討 |
| 🟡 **parked** | ドメインパーキング | 監視継続 |
| 🟢 **legitimate** | 正規サイト（誤検知） | 対応不要 |
| ⚪ **unknown** | 判定不能 | 手動確認 |

## 分析の仕組み

### 入力情報

AIは以下の情報を総合的に分析します：

- Webページのスクリーンショット
- HTMLコンテンツ
- ドメイン名の類似度
- SSL証明書情報
- WHOIS情報

### 出力情報

| 項目 | 説明 |
|------|------|
| category | 5分類のいずれか |
| confidence | 判定の確信度（0-100%） |
| reasoning | 判定理由の説明 |

### 判定例

```json
{
  "category": "phishing",
  "confidence": 95,
  "reasoning": "御社ロゴと酷似した画像を使用。ログインフォームがあり、
               認証情報の窃取を目的としたフィッシングサイトと判断。
               ドメインはexamp1e-bank.comで、公式のexample-bank.co.jpと
               視覚的に類似している。"
}
```

## リスクスコア

0-100の数値で脅威のリスクを評価します。

### スコアの目安

| スコア | リスクレベル | 対応目安 |
|--------|------------|---------|
| 80-100 | 🔴 高リスク | 即時対応 |
| 60-79 | 🟠 中リスク | 24時間以内に対応 |
| 40-59 | 🟡 要注意 | 1週間以内に確認 |
| 0-39 | 🟢 低リスク | 監視継続 |

### スコア算出要素

リスクスコアは複数の要素を加重平均して算出します：

| 要素 | 重み | 説明 |
|------|------|------|
| AI分類結果 | 40% | phishing=100, brand_abuse=70, parked=30, legitimate=0 |
| ドメイン類似度 | 25% | 公式ドメインとの文字列類似度 |
| コンテンツリスク | 20% | ログインフォーム、個人情報入力欄の有無 |
| SSL状態 | 10% | 無効な証明書、自己署名証明書 |
| WHOIS情報 | 5% | 匿名登録、最近の登録日 |

## 判定精度

### 現在の精度指標

| 指標 | 数値 | 説明 |
|------|------|------|
| 適合率（Precision） | 92% | フィッシング判定のうち実際にフィッシングだった割合 |
| 再現率（Recall） | 88% | 実際のフィッシングのうち検知できた割合 |
| F1スコア | 90% | 適合率と再現率の調和平均 |

### 改善の取り組み

- 検知パターンのフィードバックループ
- 業界固有の学習データの蓄積
- 誤検知レポートの分析

## ダッシュボード表示

ダッシュボードでは、リスクスコアを視覚的に表示します：

- **信号機方式**: 赤・黄・緑で直感的に把握
- **ソート・フィルタ**: リスク順、カテゴリ別に絞り込み
- **詳細パネル**: クリックでAI判定理由を確認
