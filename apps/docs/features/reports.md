# レポート

ThreatGuardは、監視・対応状況を自動でレポート化します。

## レポートの種類

### 月次PDFレポート

すべてのプランでご利用いただけます。

#### 内容

- **検知サマリー**: 期間中に検知した脅威の件数・傾向
- **リスク分布**: カテゴリ別、リスクスコア別の内訳
- **対応状況**: テイクダウン申請の進捗
- **トレンド分析**: 前月比較、増減傾向

#### 用途

- 定例会議での報告
- 経営層へのブリーフィング
- 監査対応の基礎資料

### 金融庁Excelレポート

::: info Professional以上
この機能はProfessionalプラン以上でご利用いただけます。
:::

金融庁への報告フォーマットに準拠したExcelレポートを出力します。

#### 対応ガイドライン

- 金融分野におけるサイバーセキュリティガイドライン
- フィッシング対策ガイドライン

#### 内容

- インシデント一覧
- 対応状況
- 再発防止策

::: warning
現在、金融庁Excelフォーマットの詳細仕様を確認中です。最新情報についてはお問い合わせください。
:::

### カスタムレポート

::: info Enterprise以上
この機能はEnterpriseプラン以上でご利用いただけます。
:::

御社の要件に合わせたカスタムレポートを作成します。

#### カスタマイズ例

- 取締役会向けエグゼクティブサマリー
- グループ会社横断レポート
- 特定期間・特定ブランドの詳細分析

## レポート出力方法

1. ダッシュボードの「レポート」メニューを開く
2. レポートの種類を選択
3. 期間を指定
4. 「生成」をクリック
5. PDFまたはExcelでダウンロード

## 自動配信

レポートの自動配信を設定できます。

| 設定項目 | オプション |
|----------|-----------|
| 配信頻度 | 毎月、毎週、毎日 |
| 配信先 | メールアドレス（複数可） |
| フォーマット | PDF、Excel |

## レポートサンプル

月次PDFレポートのサンプル構成：

```
1. エグゼクティブサマリー
   - 主要指標（KPI）
   - 重要インシデント

2. 検知状況
   - 新規検知件数
   - カテゴリ別内訳
   - リスクスコア分布

3. 対応状況
   - テイクダウン申請件数
   - 完了率
   - 平均対応時間

4. トレンド分析
   - 月次推移グラフ
   - 攻撃パターンの変化

5. 推奨アクション
   - 優先対応リスト
   - 改善提案
```
