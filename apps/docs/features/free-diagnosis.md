# 無料診断

ThreatGuardの無料診断で、御社ドメインのフィッシングリスクを確認できます。

## 無料診断の内容

| 項目 | 説明 |
|------|------|
| ドメインスキャン | 類似ドメインの検出 |
| 脅威一覧 | 検出された脅威のリスト |
| AIリスク判定 | 各脅威のリスクスコア |
| 推定被害額 | フィッシング被害の概算 |

## 利用条件

- **対象**: 1ドメイン
- **期間**: 14日間
- **回数**: 1回

## 診断の流れ

```
1. メールアドレスを入力
   ↓
2. 診断対象ドメインを入力
   ↓
3. 診断開始（数分で完了）
   ↓
4. 結果をダッシュボードで確認
   ↓
5. 14日間、継続的に監視
```

## 診断結果の見方

### 類似ドメイン一覧

検出された類似ドメインが表示されます。

- **上位5件**: 詳細情報を表示
- **6件目以降**: ぼかし表示（契約後に閲覧可能）

### リスクスコア

各脅威のリスクを0-100で評価します。

| スコア | 意味 |
|--------|------|
| 80以上 | 即時対応が必要 |
| 60-79 | 要注意 |
| 60未満 | 低リスク |

### 推定被害額

フィッシング被害が発生した場合の概算被害額を表示します。

::: warning
推定被害額は過去のインシデント統計に基づく参考値です。実際の被害額を保証するものではありません。
:::

## 期限切れ後

14日間の診断期間が終了すると：

- **継続表示**: 件数・スコアの概要
- **詳細ロック**: 個別脅威の詳細は非表示
- **週次通知**: 「脅威が○件増えています」のメール

継続して詳細を確認するには、有料プランへのアップグレードが必要です。

## テイクダウンについて

無料診断では、脅威の**検知**のみ対応しています。

テイクダウン申請を行うには、有料プランへのアップグレードが必要です。

## よくある質問

### Q. 診断に必要な情報は？

メールアドレスと診断対象ドメインのみです。技術的な設定は不要です。

### Q. 診断結果は他者に共有されますか？

いいえ。診断結果はご登録いただいたアカウントのみで閲覧可能です。

### Q. 14日後に自動で課金されますか？

いいえ。無料診断から有料プランへの自動移行はありません。
