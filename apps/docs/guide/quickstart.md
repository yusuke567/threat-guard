# クイックスタート

ThreatGuardを使い始めるまでの手順を説明します。

## 1. アカウント作成

1. [ThreatGuard](https://app.threatguard.jp)にアクセス
2. 「新規登録」をクリック
3. メールアドレスとパスワードを入力
4. 確認メールのリンクをクリックしてアカウントを有効化

## 2. 組織情報の設定

ログイン後、以下の情報を設定します：

- **組織名**: 御社名
- **Slack Webhook URL**（任意）: 脅威検知時の通知先

## 3. 保護対象ブランドの登録

「ブランド管理」から保護対象を登録します：

| 項目 | 説明 | 例 |
|------|------|-----|
| ブランド名 | 保護対象のブランド | Example Bank |
| プライマリドメイン | メインのドメイン | example-bank.co.jp |
| キーワード | 検知に使用するキーワード | examplebank, エグザンプル銀行 |
| ロゴ画像 | 類似画像検索に使用 | logo.png |

## 4. 保有ドメインの登録

御社が保有する正規ドメインを登録します。これにより：

- ホワイトリストとして除外される
- ドメイン期限切れを監視できる

## 5. 監視開始

設定が完了すると、自動的に監視が開始されます：

- **6時間ごと**にスキャンを実行
- 脅威を検知するとSlack/メールで通知
- ダッシュボードでリアルタイムに確認可能

## 6. 脅威への対応

脅威を検知したら：

1. ダッシュボードで詳細を確認
2. AIのリスク判定を参考に対応を決定
3. 必要に応じて「テイクダウン申請」を作成
4. 進捗を追跡

## サポート
