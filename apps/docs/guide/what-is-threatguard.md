# ThreatGuardとは

ThreatGuardは、**ブランドなりすまし検知・テイクダウン支援SaaS**です。

フィッシングサイトや偽アカウントなどの脅威を自動検知し、削除申請（テイクダウン）までをサポートします。

## こんな課題を解決します

| 課題 | ThreatGuardの解決策 |
|------|-------------------|
| フィッシングサイトを発見できない | 24時間自動監視で早期発見 |
| 発見しても対応方法がわからない | ワンクリックで削除申請を作成 |
| セキュリティ専門家がいない | AIが脅威を自動評価・優先度付け |
| 監査対応の報告書作成が大変 | コンプライアンスレポートを自動生成 |

## 主な機能

### 1. 脅威検知

- **類似ドメイン監視**: 御社ドメインに似た不審なドメインを自動検知
- **SSL証明書監視**: Certificate Transparency（CT）ログを監視し、新規発行された不審な証明書を検知
- **SNS監視**: Twitter/X、Facebook等での不正投稿を検知
- **コンテンツ分析**: Webページの内容を分析し、フィッシングの可能性を判定

### 2. AIリスク判定

検知した脅威をAIが自動分析し、5段階で分類します：

| 分類 | 説明 | 対応 |
|------|------|------|
| 🔴 phishing | フィッシング確定 | 即時テイクダウン |
| 🟠 brand_abuse | ブランド悪用の疑い | 要調査 |
| 🟡 parked | ドメインパーキング | 監視継続 |
| 🟢 legitimate | 正規サイト | 対応不要 |
| ⚪ unknown | 判定不能 | 手動確認 |

### 3. テイクダウン申請

- 削除申請メールを**自動生成**
- ドメイン登録者、ホスティング事業者へのAbuse報告
- Google Safe Browsing、Microsoft SmartScreenへの報告
- 対応状況の追跡・管理

### 4. レポート

- **月次レポート**: 検知・対応状況のサマリー（PDF）
- **金融庁対応レポート**: 規制当局への報告用（Excel）
- **取締役会向けレポート**: 経営層へのブリーフィング資料

## ご利用の流れ

```
1. アカウント作成
   ↓
2. 保護対象ドメインを登録
   ↓
3. 自動監視スタート
   ↓
4. 脅威を検知したらアラート通知
   ↓
5. ダッシュボードで確認・対応
```
