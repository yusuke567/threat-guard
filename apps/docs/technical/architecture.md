## コンポーネント詳細

### Web UI（フロントエンド）

| 項目 | 詳細 |
|------|------|
| フレームワーク | Next.js 14（App Router） |
| 言語 | TypeScript |
| スタイル | Tailwind CSS |
| 状態管理 | React Hooks |
| ホスティング | Vercel |

**主要ページ**:
- ダッシュボード: KPI表示、脅威サマリー
- 脅威一覧: 検知脅威のテーブル表示
- 脅威詳細: 個別脅威の詳細・対応
- ブランド管理: 保護対象の設定
- テイクダウン: 申請作成・管理
- レポート: PDF/Excel出力

### API（バックエンド）

| 項目 | 詳細 |
|------|------|
| フレームワーク | Express.js |
| 言語 | TypeScript |
| ORM | Prisma |
| 認証 | JWT |
| ホスティング | Railway |

**主要エンドポイント**:

```
認証
  POST /api/auth/login
  POST /api/auth/signup
  POST /api/auth/forgot-password

ブランド
  GET/POST /api/brands
  GET/PUT/DELETE /api/brands/:id

脅威
  GET /api/threats
  GET/PUT /api/threats/:id

テイクダウン
  GET/POST /api/takedowns
  PUT /api/takedowns/:id

スキャン
  GET /api/scans
  POST /api/scans/trigger
```

## データフロー

### 脅威検知フロー

```
1. スケジューラ起動（6時間ごと）
       │
       ▼
2. CT Monitor
   └── crt.sh API → 新規証明書を取得
       │
       ▼
3. Domain Generator
   └── 類似ドメインを生成・検索
       │
       ▼
4. Web Prober
   └── Playwright → スクリーンショット、詳細情報取得
       │
       ▼
5. Threat Analyzer
   └── Claude API → 脅威分類・確信度
       │
       ▼
6. Risk Scorer
   └── リスクスコア算出（0-100）
       │
       ▼
7. DetectedDomain テーブルに保存
       │
       ▼
8. 通知（Slack / Email）
```

### テイクダウンフロー

```
1. ユーザーが「テイクダウン申請」をクリック
       │
       ▼
2. WHOIS Abuse
   └── Abuse連絡先を自動取得
       │
       ▼
3. Takedown Generator
   └── Claude API → 申請メール生成（日本語/英語自動選択）
       │
       ▼
4. ユーザーが内容確認・送信
       │
       ▼
5. TakedownRequest テーブルに保存
       │
       ▼
6. 進捗追跡・ステータス更新
```

## スケーラビリティ

### 水平スケーリング

| コンポーネント | スケーリング方式 |
|---------------|----------------|
| Web UI | Vercel自動スケーリング |
| API | Railway水平スケーリング |
| データベース | Read Replica追加 |
| Redis | ElastiCacheクラスター |

### パフォーマンス目標

| 指標 | 目標値 |
|------|--------|
| API応答時間（p95） | < 500ms |
| ページ読み込み時間 | < 2秒 |
| スキャン処理時間 | < 5分/ブランド |
| 同時接続数 | 1,000ユーザー |
