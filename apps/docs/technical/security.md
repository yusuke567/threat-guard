# セキュリティ

ThreatGuardのセキュリティ対策について説明します。

## セキュリティ概要

ThreatGuardは、お客様のブランドを保護するサービスとして、高いセキュリティ基準を維持しています。

## 認証・認可

### 認証方式

| 方式 | 詳細 |
|------|------|
| メール/パスワード認証 | bcryptによるパスワードハッシュ |
| JWT | RS256署名、有効期限24時間 |
| SSO（Professional以上） | SAML 2.0 / OIDC対応 |

### パスワードポリシー

- 最小8文字
- 英大文字、英小文字、数字を含む
- bcrypt（コスト係数12）でハッシュ化

### アクセス制御

| レベル | 説明 |
|--------|------|
| 組織レベル | ユーザーは所属組織のデータのみアクセス可能 |
| ロールベース | admin（管理者）、member（一般） |
| リソースベース | ブランド単位でのアクセス制御 |

## データ保護

### 通信の暗号化

| 項目 | 詳細 |
|------|------|
| プロトコル | TLS 1.3 |
| 証明書 | Let's Encrypt（自動更新） |
| HSTS | 有効（max-age=31536000） |

### 保存データの暗号化

| データ | 暗号化方式 |
|--------|-----------|
| データベース | AWS RDS暗号化（AES-256） |
| ファイルストレージ | S3サーバーサイド暗号化（SSE-S3） |
| バックアップ | 暗号化済み |

### 機密データの取り扱い

| データ種別 | 保護方式 |
|-----------|---------|
| パスワード | bcryptハッシュ（不可逆） |
| APIキー | 環境変数（Secrets Manager） |
| セッショントークン | httpOnly、Secure Cookie |

## インフラストラクチャセキュリティ

### ホスティング

| サービス | 認証/規格 |
|----------|----------|
| AWS | SOC 2 Type II、ISO 27001 |
| Vercel | SOC 2 Type II |

### ネットワーク

| 対策 | 詳細 |
|------|------|

### アクセス管理

| 対策 | 詳細 |
|------|------|
| 本番環境アクセス | 多要素認証必須 |
| 管理者権限 | 最小権限の原則 |
| 監査ログ | CloudTrailで全操作記録 |

## アプリケーションセキュリティ

### 脆弱性対策

| 脆弱性 | 対策 |
|--------|------|
| SQLインジェクション | Prisma ORM（パラメータ化クエリ） |
| XSS | React自動エスケープ、CSP |
| CSRF | SameSite Cookie、トークン検証 |
| 認証バイパス | JWT検証、セッション管理 |

### セキュリティヘッダー

```
Content-Security-Policy: default-src 'self'
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
X-XSS-Protection: 1; mode=block
Strict-Transport-Security: max-age=31536000; includeSubDomains
```

### 依存関係管理

| 対策 | 詳細 |
|------|------|
| 脆弱性スキャン | npm audit（週次） |
| 依存関係更新 | Dependabot |
| ライセンス監査 | license-checker |

## 監査・ログ

### 監査ログ

以下の操作を記録しています：

- ログイン/ログアウト
- ブランド作成/更新/削除
- テイクダウン申請
- 設定変更
- 管理者操作

### ログ保持期間

| ログ種別 | 保持期間 |
|----------|---------|
| アクセスログ | 90日 |
| 監査ログ | 1年 |
| エラーログ | 30日 |

## インシデント対応

### 対応プロセス

1. **検知**: 監視システムまたはユーザー報告
2. **トリアージ**: 影響範囲・緊急度の評価
3. **封じ込め**: 被害拡大の防止
4. **根本原因分析**: 原因の特定
5. **復旧**: システムの正常化
6. **事後対応**: 報告、再発防止策
