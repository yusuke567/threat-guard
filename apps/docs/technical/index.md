# 技術詳細

このセクションでは、ThreatGuardの技術的な詳細を説明します。セキュリティ担当者（CISO）や技術部門向けの情報です。

## 概要

ThreatGuardは、以下の技術スタックで構築されています：

| レイヤー | 技術 |
|---------|------|
| バックエンド | Node.js + Express.js + TypeScript |
| フロントエンド | Next.js 14 + React |
| データベース | PostgreSQL |
| ORM | Prisma |
| AI/LLM | Anthropic Claude API |
| スクリーンショット | Playwright（Chromium） |
| インフラ | AWS（東京リージョン） |

## 主要コンポーネント

### 脅威検知エンジン

| コンポーネント | 機能 |
|---------------|------|
| CT Monitor | Certificate Transparencyログの監視 |
| Domain Generator | 類似ドメインの生成・検索 |
| Web Prober | Webページの詳細情報取得 |
| Content Analyzer | ページコンテンツの分析 |

### AI分析エンジン

| コンポーネント | 機能 |
|---------------|------|
| Threat Analyzer | Claude APIによる脅威分類 |
| Risk Scorer | リスクスコアの算出 |
| Image Similarity | 画像類似度検索 |

### テイクダウンエンジン

| コンポーネント | 機能 |
|---------------|------|
| WHOIS Abuse | Abuse連絡先の自動取得 |
| Takedown Generator | 申請メールの自動生成 |
| Browser Report | ブラウザベンダーへの報告 |
