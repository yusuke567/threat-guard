# リスクスコアアルゴリズム

ThreatGuardのリスクスコア算出ロジックの詳細を説明します。

## 概要

リスクスコアは、検知した脅威の危険度を**0〜100の数値**で表します。複数の評価要素を加重平均して算出します。

## 算出式

```
リスクスコア = Σ (要素スコア × 重み) / Σ 重み
```

## 評価要素

### 1. AI分類結果（重み: 40%）

Claude AIによる脅威分類をスコア化します。

| 分類 | スコア |
|------|--------|
| phishing | 100 |
| brand_abuse | 70 |
| parked | 30 |
| unknown | 50 |
| legitimate | 0 |

**AI確信度による調整**:
```
調整後スコア = 基本スコア × 確信度
```

例: phishing判定（確信度85%）の場合
```
100 × 0.85 = 85点
```

### 2. ドメイン類似度（重み: 25%）

公式ドメインとの文字列類似度をスコア化します。

**類似度計算**:
- レーベンシュタイン距離
- Jaro-Winkler類似度
- ホモグリフ検出

| 類似度 | スコア |
|--------|--------|
| 90%以上 | 100 |
| 80-89% | 80 |
| 70-79% | 60 |
| 60-69% | 40 |
| 60%未満 | 20 |

**ホモグリフ検出時のボーナス**:
視覚的に酷似した文字（例: a→α, o→0）を使用している場合、+20点

### 3. コンテンツリスク（重み: 20%）

ページコンテンツを分析してリスクを評価します。

| 要素 | 加算スコア |
|------|-----------|
| ログインフォームあり | +30 |
| パスワード入力欄あり | +20 |
| クレジットカード入力欄あり | +30 |
| 個人情報入力欄あり | +20 |
| 公式ロゴの使用 | +15 |
| 緊急性を煽る文言 | +10 |

**上限**: 100点

### 4. SSL状態（重み: 10%）

SSL/TLS証明書の状態を評価します。

| 状態 | スコア |
|------|--------|
| 無効な証明書 | 80 |
| 自己署名証明書 | 70 |
| 無料証明書（Let's Encrypt等） | 40 |
| 有効な商用証明書 | 20 |
| EV証明書 | 0 |

**発行日による調整**:
発行から7日以内の場合、+20点

### 5. WHOIS情報（重み: 5%）

ドメイン登録情報を評価します。

| 要素 | 加算スコア |
|------|-----------|
| 匿名登録（Privacy Protection） | +30 |
| 登録から30日以内 | +40 |
| 登録から90日以内 | +20 |
| 無料レジストラ使用 | +10 |
| 登録国が高リスク地域 | +20 |

**上限**: 100点

## 計算例

### 例1: 高リスクなフィッシングサイト

```
検出ドメイン: examp1e-bank.com（example-bank.co.jpの偽サイト）

1. AI分類: phishing（確信度95%）
   → 100 × 0.95 = 95点

2. ドメイン類似度: 88%（ホモグリフ検出）
   → 80 + 20 = 100点

3. コンテンツリスク: ログイン+パスワード+ロゴ
   → 30 + 20 + 15 = 65点

4. SSL状態: Let's Encrypt（発行3日前）
   → 40 + 20 = 60点

5. WHOIS: 匿名登録、登録から7日
   → 30 + 40 = 70点

リスクスコア = (95×40 + 100×25 + 65×20 + 60×10 + 70×5) / 100
            = (3800 + 2500 + 1300 + 600 + 350) / 100
            = 85.5点 → 86点（四捨五入）
```

### 例2: 低リスクなパーキングドメイン

```
検出ドメイン: example-bank.net

1. AI分類: parked（確信度90%）
   → 30 × 0.90 = 27点

2. ドメイン類似度: 75%
   → 60点

3. コンテンツリスク: 広告のみ
   → 0点

4. SSL状態: なし
   → 30点

5. WHOIS: 登録から2年
   → 0点

リスクスコア = (27×40 + 60×25 + 0×20 + 30×10 + 0×5) / 100
            = (1080 + 1500 + 0 + 300 + 0) / 100
            = 28.8点 → 29点
```

## リスクレベル分類

| スコア範囲 | レベル | 表示 | 推奨対応 |
|-----------|--------|------|---------|
| 80-100 | 高リスク | 🔴 | 即時テイクダウン |
| 60-79 | 中リスク | 🟠 | 24時間以内に対応 |
| 40-59 | 要注意 | 🟡 | 1週間以内に確認 |
| 0-39 | 低リスク | 🟢 | 監視継続 |

## 技術的な実装

リスクスコアの算出は `risk-scorer.ts` で実装されています。

```typescript
// 簡略化したコード例
function calculateRiskScore(threat: DetectedDomain): number {
  const weights = {
    aiClassification: 0.40,
    domainSimilarity: 0.25,
    contentRisk: 0.20,
    sslStatus: 0.10,
    whoisInfo: 0.05,
  };

  const scores = {
    aiClassification: getAIScore(threat.analysis),
    domainSimilarity: getSimilarityScore(threat.domain, threat.brand.primaryDomain),
    contentRisk: getContentScore(threat.webProbe),
    sslStatus: getSSLScore(threat.sslInfo),
    whoisInfo: getWHOISScore(threat.whoisInfo),
  };

  let totalScore = 0;
  for (const [key, weight] of Object.entries(weights)) {
    totalScore += scores[key] * weight;
  }

  return Math.round(totalScore);
}
```
