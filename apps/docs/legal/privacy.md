# プライバシーポリシー

最終更新日: 2026年4月1日

ThreatGuard（以下「当社」）は、当社が提供するサービス「ThreatGuard」（以下「本サービス」）における個人情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

## 1. 収集する情報

当社は、本サービスの提供にあたり、以下の情報を収集します。

### 1.1 ユーザーから提供される情報

| 情報の種類 | 例 |
|-----------|-----|
| アカウント情報 | メールアドレス、パスワード、氏名、所属組織 |
| 連絡先情報 | 電話番号、住所 |
| 支払い情報 | クレジットカード情報、請求先情報 |

### 1.2 本サービスの利用により収集される情報

| 情報の種類 | 例 |
|-----------|-----|
| 利用ログ | アクセス日時、操作履歴、閲覧ページ |
| デバイス情報 | IPアドレス、ブラウザ種類、OS |
| 脅威検知データ | 検出ドメイン、スクリーンショット、分析結果 |

### 1.3 Cookieおよび類似技術

当社は、以下の目的でCookieを使用します：

- ユーザー認証の維持
- サービスの利用状況の分析
- サービスの改善

## 2. 情報の利用目的

収集した情報は、以下の目的で利用します：

1. **サービス提供**: 本サービスの提供、運営、維持
2. **ユーザー対応**: お問い合わせへの対応、サポートの提供
3. **サービス改善**: 本サービスの機能改善、新機能の開発
4. **通知**: 重要なお知らせ、セキュリティ情報の通知
5. **課金**: 利用料金の請求、決済処理
6. **分析**: 利用状況の統計分析（個人を特定しない形式）

## 3. 情報の第三者提供

当社は、以下の場合を除き、個人情報を第三者に提供しません：

1. **ユーザーの同意がある場合**
2. **法令に基づく場合**: 裁判所、警察等からの法令に基づく開示請求
3. **業務委託先**: サービス提供に必要な範囲で、適切な契約の下、業務委託先に提供する場合
4. **合併・事業譲渡**: 事業承継に伴い個人情報を移転する場合

### 業務委託先

当社は、以下の業務委託先にデータ処理を委託しています：

| 委託先 | 目的 |
|--------|------|
| Amazon Web Services | インフラストラクチャ（日本リージョン） |
| Anthropic | AI分析処理 |
| Resend | メール送信 |
| Stripe | 決済処理 |

## 4. 情報の保管

### 4.1 保管場所

個人情報は、日本国内のデータセンター（AWS東京リージョン）に保管されます。

### 4.2 保管期間

| 情報の種類 | 保管期間 |
|-----------|---------|
| アカウント情報 | アカウント削除後3年 |
| 利用ログ | 収集から1年 |
| 脅威検知データ | 収集から5年 |
| 支払い情報 | 法令で定められた期間 |

### 4.3 安全管理措置

当社は、個人情報の漏洩、滅失、毀損を防止するため、以下の措置を講じています：

- **技術的措置**: 通信の暗号化（TLS）、保存データの暗号化、アクセス制御
- **組織的措置**: 従業員教育、アクセス権限の管理
- **物理的措置**: データセンターのセキュリティ対策

## 5. ユーザーの権利

ユーザーは、自己の個人情報について、以下の権利を有します：

1. **開示請求**: 保有する個人情報の開示を請求する権利
2. **訂正請求**: 不正確な情報の訂正を請求する権利
3. **削除請求**: 個人情報の削除を請求する権利
4. **利用停止請求**: 個人情報の利用停止を請求する権利

これらの請求は、以下の連絡先までお申し出ください。

## 6. 未成年者の個人情報

本サービスは、法人および18歳以上の個人を対象としています。18歳未満の方からの個人情報の収集は行いません。

## 7. 本ポリシーの変更

当社は、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、本サービス上で通知します。
